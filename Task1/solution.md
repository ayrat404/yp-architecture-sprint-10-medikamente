# Анализ безопасности системы

## 1. Конфиденциальные данные

- **Персональные данные пациентов**: ФИО, дата рождения, телефон, email
- **Расширенные данные**: адрес прописки, место работы/учебы, хронические заболевания
- **Медицинские данные**: результаты анализов, медицинские карты, заключения врачей
- **Финансовые данные**: платежи, счета, бухгалтерские записи
- **Кадровые данные**: зарплаты, личные данные сотрудников

## 2. Аудит мер по обеспечению безопасности данных

### Проблемные зоны:

1. Отсутствие шифрования данных
   - Excel файлы хранятся в открытом виде
   - Медицинские сканы без защиты
   - Отсутствие шифрования при передаче

2. Недостаточный контроль доступа
   - Общий доступ к файлам на диске
   - Отсутствие разграничения прав
   - Нет аудита действий пользователей

3. Уязвимости в интеграциях
   - OLE соединения без шифрования
   - TCP/IP соединения без защиты
   - Отсутствие валидации данных

4. Отсутствие резервного копирования
   - Нет системы бэкапов
   - Риск потери данных
   - Отсутствие плана восстановления

5. Несоответствие требованиям ФЗ-152
   - Отсутствие согласий на обработку ПД
   - Нет системы уведомлений об утечках
   - Отсутствие политик обработки данных

## 3. Улучшения и меры защиты

### Данные для защиты и способы защиты:

| Тип данных                                                                     | Способ защиты              |
|--------------------------------------------------------------------------------|----------------------------|
| Персональные данные (ФИО, дата рождения, телефон, email)                       | Шифрование + обезличивание |
| Расширенные персональные данные (адрес, место работы, хронические заболевания) | Шифрование + обезличивание |
| Медицинские данные (анализы, диагнозы, заключения)                             | Шифрование + обфускация    |
| Финансовые данные (платежи, счета, зарплаты)                                   | Шифрование + обфускация    |
| Логи доступа и аудита                                                          | Шифрование + обезличивание |

### Механизм тегирования данных:

- **Персональные данные пациентов** - `pii_patient`
- **Расширенные данные** - `pii_extended`
- **Медицинские данные** - `medical_data`
- **Финансовые данные** - `financial_data`
- **Кадровые данные** - `hr_data`

### Инструменты и меры защиты:

1. **Шифрование данных**
   - BitLocker для дисков
   - PGP для файлов
   - TLS для сетевых соединений

2. **Контроль доступа**
   - Active Directory с RBAC
   - Многофакторная аутентификация
   - Принцип минимальных привилегий

3. **Мониторинг и аудит**
   - SIEM система
   - Логирование всех операций
   - Алерты на подозрительную активность

4. **Резервное копирование**
   - Автоматические бэкапы
   - Географически распределенное хранение
   - Тестирование восстановления
