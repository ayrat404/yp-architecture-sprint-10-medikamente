# Классификация данных и стратегия защиты

| Данные                                                                             | В чём необходимость защиты                                                       | Инструменты защиты                                                      |
|------------------------------------------------------------------------------------|----------------------------------------------------------------------------------|-------------------------------------------------------------------------|
| **Персональные данные пациентов** (ФИО, дата рождения, телефон, email)             | Требования ФЗ "О персональных данных", репутационные риски, штрафы до 6 млн руб. | Шифрование AES-256, токенизация, RBAC, аудит доступа                    |
| **Медицинские карты** (диагнозы, анализы, заключения)                              | Врачебная тайна, уголовная ответственность, доверие пациентов                    | Шифрование на уровне БД, DLP-системы, цифровые подписи, изоляция данных |
| **Расширенные персональные данные** (адрес, место работы, хронические заболевания) | Особые категории ПД, повышенные требования защиты                                | Дополнительное шифрование, анонимизация, строгий контроль доступа       |
| **Финансовые данные** (платежи, счета, ККМ данные)                                 | Требования законов, налоговая отчетность                                         | TLS 1.3, шифрование платежных данных                                    |
| **Журналы записей к врачам**                                                       | Врачебная тайна, конфиденциальность расписания                                   | Шифрование файлов, контроль версий, резервное копирование               |
| **Данные сотрудников** (кадровый учет, зарплаты)                                   | Трудовое законодательство, персональные данные сотрудников                       | Шифрование HR-систем, разделение доступа, аудит                         |
| **Материальные ценности**                                                          | Коммерческая тайна, учетные данные                                               | Шифрование складских систем, контроль инвентаризации                    |
| **Данные лабораторных анализов**                                                   | Медицинская тайна, точность результатов                                          | Шифрование результатов, цифровые подписи, целостность данных            |
| **Системные логи и аудит**                                                         | Расследование инцидентов, соответствие требованиям                               | Централизованное логирование, SIEM, неизменяемые журналы                |
| **Резервные копии**                                                                | Восстановление после сбоев, защита от потери данных                              | Шифрование бэкапов, тестирование восстановления                         |
